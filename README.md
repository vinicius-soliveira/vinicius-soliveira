# Vinicius Oliveira

**Embedded Systems & Firmware Engineer**  
*C/C++ · Real-Time Systems · Hardware/Software Integration · FPGA & Digital Design*

I'm an electrical engineer working on embedded firmware, instrumentation, and motion control at the **Brazilian Synchrotron Light Laboratory (LNLS/CNPEM)**. My work focuses on developing reliable hardware/software solutions for scientific equipment, from low-level interfaces and firmware to system integration and testing.

I'm also expanding my work into **FPGA/ASIC front-end design and verification**, with an interest in architectures that connect embedded software and digital hardware.

## Professional background

At LNLS/CNPEM, I have worked on firmware and electronic instrumentation for synchrotron beamlines and, more recently, motion-control systems. My experience includes microcontroller-based applications, communication interfaces, real-time behavior, device integration, debugging, and engineering automation.

I value clear interfaces, reproducible testing, and practical engineering trade-offs.

## Selected projects

**[AXI DMA Controller](https://github.com/vinicius-soliveira/axi-dma)**  
A SystemVerilog memory-to-memory DMA controller with AXI4 and AXI-Lite interfaces. Includes RTL, a verification environment, synthesis, timing analysis, and gate-level simulation flows.

**[Signal Tools](https://github.com/vinicius-soliveira/signal-tools)**  
A Python toolkit for engineering time-series data, including signal visualization, alignment, transformations, statistical metrics, and tracking-error analysis.

**[Embedded Systems Engineering Library](https://github.com/vinicius-soliveira/embedded-systems-engineering-library)**  
An organized technical reference covering embedded software, RTOS, digital design, verification, SoC architecture, tooling, and systems engineering.
